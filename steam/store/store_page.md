# Frostline — Steam store page kit

Everything to paste into **Steamworks → Store Page Admin**. Copy files next to this one:
`short_description.txt` (223 / 300 chars) and `about_this_game.txt` (Steam markup: `[h2]`, `[list]`, `[*]`, `[b]`).
Check the feature bullets against the build you ship: Valve's review rejects claims the game can't back up.

- **Name:** Frostline
- **Tagline (used in trailers and capsules):** Ski. Hunt. Build. Outlast the cold.

- **Controller support:** Full controller support (Xbox / PlayStation / Steam Deck built-in controls)
- **Single-player** · **Steam Achievements** · **Steam Cloud** · **Family Sharing**
