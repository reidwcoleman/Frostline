# Frostline

*Ski. Hunt. Build. Outlast the cold.*

Frostline is a first-person alpine survival game for Steam. You're stranded in a ring of mountains with skis,
a hatchet and the cold. Carve down untouched powder, hunt deer, hold off wolves, fell trees and raise a log
cabin, then survive as many days as you can.

Everything is procedural (terrain, forests, sky, weather, audio). Stack: **TypeScript + three.js (WebGL2) +
Vite**, shipped as an **Electron** desktop app with **Steamworks** (achievements, stats, Cloud saves, overlay).

## Run it

```bash
npm install
npm run dev            # browser: http://127.0.0.1:5317
npm run electron:dev   # desktop window on top of the dev server (starts Vite if it isn't running)
```

Dev URL parameters (browser or `--frostline-query=` in Electron): `skipMenu=1`, `pos=x,z`, `yaw`, `pitch`,
`time=17.5`, `freeze=1`, `weather=blizzard`, `skis=1`, `seed=123`, `nocache=1`, `fly=1`, `god=1`.

## Build and package

```bash
npm run build          # type-check + production bundle → dist/
npm run electron:start # run the production bundle in Electron (unpackaged)
npm run dist           # package for this OS → release/
npm run dist:mac       # macOS universal .app + .dmg
npm run dist:win       # Windows x64 folder + NSIS installer
npm run dist:linux     # Linux x64 folder + AppImage
npm run smoke          # end-to-end desktop test (boot, WebGL, worker, saves, quit handshake, backup restore)
```

The desktop app serves the game from a privileged `app://frostline/` origin with a strict CSP, a sandboxed and
context-isolated renderer, and hardened Electron fuses. Saves are atomic JSON files in the OS app-data folder,
with a `.bak` fallback, and Steam Cloud syncs them.

## Ship it on Steam

The step-by-step guide is **[docs/STEAM.md](docs/STEAM.md)**: Steamworks setup, App ID, depots, launch
options per OS, Steam Cloud, achievements, the Steam Deck checklist, and build → upload → set live.

```bash
npm run steam:upload                  # prepare release/steam/*.vdf and print the steamcmd command
STEAM_BUILD_USER=... npm run steam:upload -- --run --setlive beta
```

Store copy, tags, system requirements and asset sizes: `steam/store/`. Achievement table: `steam/achievements.md`.

## Project layout

| Path | What |
|---|---|
| `src/core/` | Engine: game loop and state machine, events, input, terrain/world/physics, settings |
| `src/world/`, `src/render/` | Terrain generation (worker), terrain/vegetation/snow-trail rendering |
| `src/atmosphere/` | Sky, lighting, weather, fog, post-processing |
| `src/player/` | Skiing and walking physics, camera, first-person body |
| `src/combat/`, `src/wildlife/` | Weapons, projectiles, animals |
| `src/survival/` | Vitals, harvesting, crafting, building, fires |
| `src/ui/`, `src/audio/` | HUD, menus, map, procedural audio and music |
| `src/platform/` | Platform bridge, saves, achievements |
| `electron/` | Electron main, preload, Steam, save files, window state, dev + smoke scripts |
| `steam/` | SteamPipe build scripts, store page kit, achievements |
| `build/` | App icons (generated by `npm run icons`), macOS entitlements |
| `docs/` | `ARCHITECTURE.md` (team rules, contracts), `STEAM.md` (shipping guide) |
